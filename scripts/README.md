\# Scripts / 科研脚本



This directory stores reusable scripts for preprocessing, training, evaluation, visualization, and result analysis.



本目录用于保存可重复执行的数据预处理、训练、测试、可视化和结果分析脚本。



\---



\## 1. Core Principle / 核心原则



If a research operation needs to be repeated, it should preferably be implemented as a script.



如果某个科研操作需要反复执行，应尽量写成脚本，而不是每次手工完成。



The goal is:



目标是：



> Reproducible, traceable, and reusable research workflows.



> 让科研流程可复现、可追溯、可重复使用。



\---



\## 2. Suggested Directory Structure / 推荐目录结构



Future structure:



```text

scripts/

├── preprocess/

├── train/

├── test/

├── visualization/

└── analysis/

```



\### `preprocess/`



Data preprocessing scripts.



数据预处理脚本，例如：



\* Convert dataset format / 数据格式转换

\* Generate metadata / 生成元数据

\* Create data splits / 生成数据划分

\* Coordinate transformation / 坐标转换

\* Radar preprocessing / 雷达预处理



\---



\### `train/`



Training scripts.



训练相关脚本，例如：



```text

train\_baseline.py

train\_ours.py

```



\---



\### `test/`



Evaluation and inference scripts.



测试与推理脚本，例如：



```text

evaluate.py

inference.py

```



\---



\### `visualization/`



Visualization scripts.



可视化脚本，例如：



\* Radar point cloud visualization / 雷达点云可视化

\* Radar-to-camera projection / 雷达点投影到图像

\* BEV visualization / BEV 可视化

\* Detection visualization / 检测结果可视化



\---



\### `analysis/`



Result analysis and paper-figure generation.



结果分析和论文图片生成。



Examples:



```text

plot\_ablation.py

plot\_robustness.py

plot\_cdf.py

generate\_table.py

```



\---



\## 3. Avoid Hard-Coded Paths / 避免硬编码路径



Avoid:



避免：



```python

data\_path = "D:/mydata/xxx/xxx/xxx"

```



Prefer configuration or command-line arguments.



优先使用配置文件或命令行参数，例如：



```bash

python visualize.py --data\_root D:/datasets/VoD

```



这样代码更容易：



\* Reuse / 复用

\* Move to another machine / 换电脑

\* Share / 分享

\* Reproduce / 复现



\---



\## 4. Input and Output / 输入与输出



Every important script should clearly define:



每个重要脚本都应该明确：



\### Input / 输入



\* File

\* Directory

\* Tensor

\* Configuration

\* Dataset



\### Output / 输出



\* Processed data

\* Metrics

\* Figure

\* Log

\* Prediction



\---



\## 5. Script Documentation / 脚本说明



Important scripts should contain comments or documentation explaining:



重要脚本应说明：



\* What does it do? / 它做什么？

\* Why is it needed? / 为什么需要？

\* What is the input? / 输入是什么？

\* What is the output? / 输出是什么？

\* How to run it? / 怎么运行？



\---



\## 6. Figure Generation / 论文图片生成



Important paper figures should preferably be generated by scripts.



正式论文图片应尽量通过脚本生成。



Recommended workflow:



```text

Experiment Results

&#x20;       ↓

Analysis Script

&#x20;       ↓

Figure

&#x20;       ↓

Paper

```



This allows us to regenerate figures when experimental results change.



这样实验数据变化后，可以直接重新生成图片，而不是手工重画。



\---



\## 7. Final Principle / 最终原则



Automation is part of research engineering.



自动化本身就是科研工程化的一部分。



Whenever possible:



尽量做到：



> Run one command → obtain the same processing or analysis result.



> 一条命令 → 得到相同的数据处理或分析结果。
