# 一、Camera 与 BEV 视角变换基础

## 1. Depth Ambiguity（深度歧义）

从二维图像推断三维距离时，单凭图像投影不一定能唯一确定物体深度。针孔相机简化关系：

$$h=\frac{fH}{Z}$$

其中 $h$ 为图像高度，$f$ 为焦距，$H$ 为物体真实高度，$Z$ 为深度。例如真实高度与距离同比例变大时，图像高度可能相同。

**为什么重要？** Camera 具有视觉语义，但若深度估计不准，图像特征可能被映射到错误的 BEV 位置。

**易混淆**：Depth Ambiguity 不是 Lens Distortion（镜头畸变）；校正镜头畸变不等于解决深度歧义。

## 2. Depth Distribution（深度分布）

网络为图像位置预测多个候选深度区间的概率，而非只给一个绝对正确的距离。例如 10 m、20 m、30 m 的概率为 0.15、0.60、0.25。**预测概率不是测量真值。**

## 3. Camera-to-BEV View Transformation（相机到鸟瞰空间的视角变换）

把图像中的特征结合深度/几何关系投到 BEV 网格，使后续检测在统一俯视空间中处理。**BEV 是空间组织方式，转换本身不保证定位准确。**

## 4. Frustum（视锥）与 Frustum Feature（视锥特征）

图像像素沿不同候选深度形成三维视锥空间；结合图像语义和深度/占用信息形成视锥特征，再映射到 BEV。

```text
Image Context + Depth Distribution ─┐
                                    ├─→ Frustum Feature ─→ BEV
Image Context + Radar Occupancy ────┘
```

这是 CRN RVT 的概念化理解图，省略网络细节。

## 5. Radar Occupancy（雷达占用响应）

由雷达观测经编码预测的空间占用相关响应，用于辅助视角变换。它**不是**真实占用标签，也不意味着每个图像像素都有精确 Radar 深度。

## 6. Voxel Pooling（体素/空间网格聚合）

把映射到相同 BEV 网格的多个特征进行汇总，例如求和或平均，生成网格特征。**聚合不是生成检测框**；检测框由下游检测头预测。

## 7. BEV Feature Map（BEV 特征图）

按俯视网格排列的多通道神经网络特征，常用概念形状 $[B,C,H,W]$。$C$ 是特征通道数，不一定是类别数；$H,W$ 是网格数量，不直接等于米数。与 P001 的 BEV 基础互相参照。

# 二、CRN 的三个核心机制

## 8. RVT（Radar-assisted View Transformation，雷达辅助视角变换）

**要解决什么？** Camera 深度不确定使图像特征难以准确进入 BEV。

**做什么？** 利用 Radar 空间观测与视觉深度分布共同构建视锥特征，再变换为 Camera BEV。

**输出什么？** 供后续融合的 Camera BEV Feature，而不是 Radar-only 检测框。

**边界**：缓解深度不确定性，不保证全部像素深度正确。

## 9. MFA（Multi-modal Feature Aggregation，多模态特征聚合）

**要解决什么？** Camera BEV 与 Radar BEV 在统一网格上仍可能存在目标特征位置错位。

**做什么？** 通过 MDCA 在可能相关的位置采样并加权聚合两种模态特征。

**输出什么？** 更新后的融合 BEV 特征，供检测等任务使用。

**区别**：RVT 处理 Camera 特征**进入 BEV**；MFA 处理两种模态**已经进入 BEV 后的融合**。

## 10. MDCA（Multi-modal Deformable Cross Attention，多模态可变形交叉注意力）

围绕 Query 的参考位置学习采样偏移和权重，在 Camera/Radar BEV 的相关位置取特征并聚合。与固定位置逐点相加相比，更有机会关联发生错位的特征，但不保证自动纠正所有标定误差。

## 11. Query Feature（查询特征）

参与注意力聚合的特征向量，代表网络需要更新的信息。**Query 不是一个原始 Radar Point，也不必是目标中心。**

## 12. Reference Point（参考点）

Query 关联的空间参考位置，是采样的起点。参考点不一定等于目标真实中心。

## 13. Sampling Offset（采样偏移）

模型学习从参考点向什么位置偏移，回答**“到哪里采样”**。例如参考网格 A，但相关 Radar 特征落在 B，可学习从 B 采样。

## 14. Attention Weight（注意力权重）

模型学习不同采样结果的贡献，回答**“采到的信息占多大权重”**。概念公式：

$$f_i^{\mathrm{new}}=\sum_{k=1}^{K}w_{i,k}f_{i,k}$$

这只是简化教学公式，不等于 CRN 的完整多头、多模态实现；权重也不保证必然抑制噪声。

## 15. Sparse Aggregation（稀疏聚合）与 Top-K Query

如果每个 BEV 网格都进行较昂贵的注意力计算，开销可能较大。Sparse Aggregation 选出部分高分 Query 做重点聚合。

- K 较小：可能更快，但遗漏有效位置的风险增加。
- K 较大：保留更多信息，但计算成本上升。
- **选的是 BEV Query，不是删除 K 个雷达点。** 未选 Query 不等于整个 BEV 特征被删除。

P002 笔记所记附录示例：1,024 Query 时 Car AP 49.8 / FPS 14.1；65,536 Query 时 Car AP 56.9 / FPS 11.5。**不能把 Car AP 当成全类别 mAP，也不能把模块提速当成整机提速。**

# 三、训练、推理与任务输出

## 16. LiDAR-free Inference（无激光雷达推理）

推理阶段不输入 LiDAR；**不等于训练期间没有 LiDAR 生成的深度监督或标签**。

## 17. Depth Supervision（深度监督）

训练时使用深度标签约束 Camera 深度分支；在 CRN 学习语境中，相关深度监督可由 LiDAR 数据生成。监督来源与推理输入必须分开描述。

## 18. Detection Head（检测头）

把 BEV 特征变成类别、位置、尺寸、朝向等预测。**BEV 特征图不是最终 3D Bounding Box。**

## 19. Tracking（目标跟踪）

通过跨帧关联维持目标身份连续性。检测回答“这一帧有哪些目标”，跟踪进一步回答“前后两帧是否为同一个目标”。

## 20. BEV Segmentation（BEV 语义分割）

对鸟瞰网格进行类别预测，如可行驶区域等；不同于给每个 Radar 点分类，也不同于输出 3D Box。

# 四、实验评价与科研证据

## 21. nuScenes 与 NDS（nuScenes Detection Score）

nuScenes 是自动驾驶多传感器数据集。NDS 是结合检测表现与若干误差项的综合指标；**NDS 越高通常越好，不能与 mAP 混为同一个数。**

## 22. mATE（mean Average Translation Error，平均平移误差）

衡量预测目标中心与真值的平移误差，**越低越好**。mAP 提高不必然意味着 mATE 同时下降。

## 23. AP / mAP / Car AP 的区别

AP 是指定类别和评价协议下的平均精度；mAP 是多个类别 AP 的平均；Car AP 是汽车类别的 AP。**Car AP 不等于全类别 mAP。**

## 24. Main Results（主要实验）

比较完整模型与其他方案的总体表现。若完整 CRN 优于 BEVDepth，不能因此断言提升全部来自 RVT；还需消融验证。

## 25. Ablation Study（消融实验）

在尽量控制其他条件时去掉、替换或改变某个模块，观察性能变化。用于分析模块贡献；不能把不同 Backbone、数据划分等变化误归因于某个模块。

## 26. Controlled Variables（控制变量）

比较 Radar+Camera 与 Radar+Camera+VLM 时，应尽量保持数据划分、Backbone、训练协议和评价方法一致，才能更有依据地判断 VLM 的作用。**相关性变化不自动等于单模块因果贡献。**

## 27. View Drop / Sensor Dropout（视角丢弃／传感器输入缺失）

人为去除部分 Camera 或 Radar 输入，测试模型在指定缺失条件下的表现。**丢失 3 个 Camera 视角 ≠ 全部 Camera 失效 ≠ 全部传感器失效 ≠ 真实局部遮挡。**

## 28. Remaining Performance 与 Absolute Drop（剩余精度与绝对下降幅度）

剩余精度是退化条件下仍有多少 AP；绝对下降幅度是正常输入 AP 减去退化输入 AP。例如 CRN 68.8→48.9，下降 **19.9 个百分点**；BEVFusion 63.9→45.7，下降 **18.2 个百分点**。CRN 剩余精度更高，但绝对下降更大。注意这里是**百分点**，不是相对百分比。

## 29. Robustness（鲁棒性）与 Generalization（泛化）

鲁棒性关注扰动或输入退化时表现如何；泛化关注模型能否在未见数据或条件下保持性能。特定 View Drop 测试不能证明所有天气、遮挡或传感器故障下都更鲁棒。

## 30. FPS（Frames Per Second）与 Latency（延迟）

FPS 是单位时间处理帧数；Latency 是一次输入到输出的耗时。实际速度依赖 GPU、batch size、输入尺寸、FP16/FP32、预处理和后处理。**论文报告 FPS 不等于本机可达到的端到端实时速度。**

## 31. Research Hypothesis（研究假设）与 Conclusion Boundary（结论边界）

研究假设是**尚待实验验证**的判断，例如“VLM 能否改善部分遮挡场景中的 Radar-Camera 3D 检测”。应设基线与实验组、控制变量、确定指标，并只在测试覆盖的条件下得出结论。**CRN 没有证明加入 VLM 能提高深度估计或恶劣天气鲁棒性。**
