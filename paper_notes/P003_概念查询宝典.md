## 1. 中心点检测（Center-based Detection）｜P003-C01

| 字段 | Lesson 01记录 |
| --- | --- |
| 准确定义 | 以图像中目标中心为关键点，并在该位置估计其他属性；不等于只检测中心就获得准确3D框 |
| 通俗解释 | 先找到“在哪儿”，再补深度、尺寸、朝向等信息 |
| 数学/实现 | §3.2类别热图$\hat Y\in[0,1]^{(W/R)\times(H/R)\times C}$；是论文维度约定，不是已核代码布局 |
| 例子 | 教学例子：找到车的图像中心后，仍要估计其深度；中心像素相同不能唯一决定三维距离 |
| 误区 | CenterNet是已有基础；本文贡献不是重新提出中心点检测；二维中心不自动等于3D几何中心投影的所有定义 |
| 本文作用 | 提供初步检测与后续雷达关联所需目标信息 |
| 来源/待核 | 正式PDF§3.2/§4.1；具体实现与张量布局待第二遍，不据本节推定源码已掌握 |
| 交叉引用 | [P003精读](P003_CenterFusion.md)、[P001边界框§2–3](P001_概念查询宝典.md) |

<a id="p003-c03"></a>
## 3. 视锥（Frustum / Viewing Frustum）应用补充｜P003-C03

基本定义引用[P002§4](P002_概念查询宝典.md)，不复制CRN模块说明。CenterFusion中可直观理解为“图像区域射向空间形成候选体积，再由深度/框约束截取RoI”。教学几何关系$u=f_xX/Z+c_x$表明同一像素射线可对应不同$Z$；不是CenterFusion新公式，也不是唯一深度预测机制。

例子：同一图像区域可有前后两个目标；候选体积需进一步约束。误区：不能把视锥当作准确深度测量或正确身份标签。作用与出处：PDF§4.2/Fig.3；精确RoI参数及实现待核。[关联条目C02](#p003-c02)。

<a id="p003-c04"></a>
## 4. 早期/中间/晚期融合（Early / Middle / Late Fusion）应用补充｜P003-C04

基本定义引用[P001第三部分§1](P001_概念查询宝典.md)。Early在原始/较早数据层融合，Middle结合中间特征后继续预测，Late合并决策输出。自拟例子：拼接原始输入、拼接特征后预测、合并最终检测框分别作为三种层级的示意，具体系统需看真实流程。

CenterFusion将关联后的雷达特征与图像特征结合，后续预测深度/方向/速度等，因此是Middle Fusion（PDF第2页、Fig.1、§4.3）。误区：有初步检测不等于整条系统是Late Fusion；只“建立关联”还不足以完整说明融合如何用于预测。实现拼接维度留待第二遍。[精读](P003_CenterFusion.md)。

<a id="p003-c05"></a>
## 5. 距离（Range）应用补充｜P003-C05

基本定义引用[P001第一部分§3](P001_概念查询宝典.md)。距离是传感器到散射点的径向距离，通俗说是“有多远”；教学坐标关系$r=\sqrt{x^2+y^2+z^2}$须在同一传感器坐标约定下使用。相机$Z$则是光轴方向深度，二者不自动相等。

自拟例子：斜前方散射点的$r$大于其光轴分量；也不保证散射点就是车中心。本文通过关联后的深度特征辅助图像估计；PDF§3.1/§4.3，不把示意$r$等同于代码中的$d$。标定、具体特征定义及误差待第二遍核。[原Q1与补学](../docs/research_log/P003_CenterFusion_REVIEW.md)。

<a id="p003-c06"></a>
## 6. 多普勒/径向速度（Doppler / Radial Velocity）应用补充｜P003-C06

主要定义引用[P001第一部分§5](P001_概念查询宝典.md)。它提供沿视线的运动分量；教学关系$v_r=\mathbf v_{rel}\cdot\hat{\mathbf r}$依符号和自车补偿约定。自拟例子：目标横向运动时径向分量可很小，不代表静止。

论文Fig.2/§3.1区分径向速度与实际运动，§4.3以径向速度分量形成特征，后续网络预测目标速度。误区：两个坐标分量不代表雷达直接测得完整二维运动；“不需额外时序信息”不抹去§3.1的多sweep输入。具体数据字段和补偿实现待源码核查。[P003精读](P003_CenterFusion.md)。

<a id="p003-c07"></a>
## 7. 雷达散射截面（Radar Cross Section, RCS）应用边界｜P003-C07

主要定义与原理引用[P001第一部分§7](P001_概念查询宝典.md)。RCS描述目标向雷达方向的散射特性，并非接收信号功率本身；通常以面积量或其对数尺度表达。通俗说是“目标在特定条件下有多显眼”，不等于物体大小真值。

自拟例子：同一目标换观察角，RCS也可能变，不能据单值推出真实尺寸。本文§4.3明确的三通道为深度与径向速度分量，没有据此确认RCS通道或RCS消融收益。补学学生说“反射强度”的原话保留，但正式理解需按教师纠正限定。具体数据文件是否含RCS与模型是否用它分开核查；本节不对未读代码作断言。[验收记录](../docs/research_log/P003_CenterFusion_REVIEW.md)。

<a id="p003-c08"></a>
## 8. 杂波/噪声/多径（Clutter / Noise / Multipath）应用补充｜P003-C08

主要定义引用[P001第一部分§20–22](P001_概念查询宝典.md)。杂波是相对任务不期望的散射，噪声是随机扰动，多径是经多条路径传播导致偏差或虚假观测；不能把三者混成一种机制。

自拟例子：路边结构回波可能不是目标车；反射路径可能产生不对应真实目标位置的观测。它们可能干扰目标关联是教学/研究风险分析，不是本文逐种干扰控制实验的既有结论。数学噪声分布、各机制比例未知；本文§4.2描述非目标检测与投影混淆，不提供本项目相关测量。待验证实验见[研究候选](../docs/innovation_bank/P003_P005_RESEARCH_QUESTIONS.md)。

<a id="p003-c09"></a>
## 9. 测量错误与关联错误（Measurement Error vs Association Error）｜P003-C09

| 字段 | Lesson 01辨析 |
| --- | --- |
| 定义 | 测量错误：位置/速度等观测偏离目标真实量；关联错误：将观测分配给错误目标，即使观测本身可能准确 |
| 通俗解释 | “量错了”与“认错归属”不是同一个问题；二者可同时发生 |
| 数学/实现原理 | 教学表示$z=h(x)+\epsilon$描述观测误差；错误目标对应另属关联变量问题。此式非CenterFusion专属模型，未假定噪声分布 |
| 例子 | 自拟：B车距离测得准确，却分给A车，是关联错误；A车量距偏差则是测量错误 |
| 误区 | 只降低传感器噪声不保证匹配正确；不能用总体AP变化独立证明哪类误差减少 |
| CenterFusion作用 | §4.2的投影、遮挡和非目标观测说明需要关联；误差拆分是教学/研究分析，不宣称本文已给两类独立误差指标 |
| 来源/待验证 | 教师纠正来自用户本次对话；相关原文§4.2。误差标签、关联真值与因果拆分实验均未执行 |
| 交叉引用 | [C02](#p003-c02)、[P001标定](P001_概念查询宝典.md)、[教师纠正](../docs/research_log/P003_CenterFusion_REVIEW.md) |

## 10. 单目深度歧义（Monocular Depth Ambiguity）应用补充｜P003-C10

| 字段 | Lesson 02记录 |
| --- | --- |
| 定义 / 主要来源 | 复用[P002§1](P002_概念查询宝典.md)：二维投影通常不能唯一决定真实深度，学习预测仍可能有误差 |
| 通俗解释 | 看见车在图像哪儿，不等于已准确知道车离相机多远 |
| 原理 / 例子 | 针孔模型中正比例放缩三维点保持像素投影；尺度、透视和训练先验提供约束而非绝对真值 |
| 常见误区 | 不是“相机不能预测深度”；水平像素相同也不代表完整二维位置相同；畸变与深度歧义分开 |
| CenterFusion作用 | 原文§1讨论图像几何估计不足，雷达可补充线索；仍需正确关联 |
| 交叉引用 / 待核 | [本节投影公式](P003_CenterFusion.md#lesson02)、[C11](#p003-c11)；未做深度误差实验 |

## 11. 相机投影（Camera Projection）应用补充｜P003-C11

主要几何定义复用[P001坐标与标定](P001_概念查询宝典.md)和[P002深度歧义](P002_概念查询宝典.md)。教学针孔关系$u=f_xX/Z+c_x, v=f_yY/Z+c_y$将相机坐标映到像素；$Z>0$、内参单位、去畸变前提须说明。例子：$(X,Y,Z)$与$(\lambda X,\lambda Y,\lambda Z)$可投影重合。这是基础模型，不是本文新公式，也不等同完整标定/畸变模型。

作用：解释为什么需三维约束并帮助建立候选对应。误区：把雷达Range直接当作相机$Z$，或认为知道像素就知道空间距离。源码投影实现未检查；见[C05](#p003-c05)、[本节几何说明](P003_CenterFusion.md#lesson02)。

## 12. 数据关联（Data Association）应用辨析｜P003-C12

| 字段 | Lesson 02记录 |
| --- | --- |
| 定义 | 在不同观测与目标之间建立对应关系；复用[P001跨模态对应基础](P001_概念查询宝典.md)，不假定候选即真值 |
| 通俗解释 | 在使用一条雷达距离/速度前，先问“它可能属于哪辆车” |
| 原理 / 实现 | 需坐标/时间一致与对应判据；本论文以视锥/候选RoI关联，通用关联不等于只能用视锥 |
| 例子 | 教学A为20 m，B为40 m且径向速度8 m/s；将B观测分配给A，即使B测量准确仍是错关联 |
| 误区 | 不能把所有点无差别地当成同一目标的属性；也不能把该论证泛化成所有融合网络必须用CenterFusion模块 |
| 本文作用 | 为目标生成相应雷达特征，后续与图像特征结合预测属性；依据§1/Fig.1、辅助§4.2 |
| 交叉引用 / 待核 | [C02视锥关联](#p003-c02)、[C09错误](#p003-c09)、[C13](#p003-c13)；关联真值、阈值与代码待核 |

<a id="p003-c13"></a>
## 13. 测量与预测（Measurement vs Prediction）｜P003-C13

| 字段 | Lesson 02记录 |
| --- | --- |
| 定义 | 测量是传感器对物理量的观测，含误差；预测是模型根据输入估计的量，也可能有误差，不等同输入观测或真实值 |
| 通俗解释 | 传进模型一个数，不代表模型最终一定输出同一个数 |
| 原理 / 示例 | 教学表示$\hat y=f(I,z,a)$，其中$I$为图像、$z$为观测、$a$为关联；这不是本文专用公式。错误$a$引入B的40 m/8 m/s，不推出$\hat y_A$必为该数值 |
| 常见误区 | “测得B”≠“直接测得A”，输入观测≠网络输出，观测/预测≠真值；“先关联再定位”不抹去图像初步预测 |
| CenterFusion作用 | Fig.1初步图像检测→雷达关联→特征融合→属性细化，关联后的观测参与预测而非保证结果 |
| 交叉引用 / 待核 | [C09错误类型](#p003-c09)、[02-R1教师纠正](../docs/research_log/P003_CenterFusion_REVIEW.md#lesson02-review)；未运行模型或测量偏移量 |

## Lesson 02对既有C02/C09的补充

- **C02 Frustum-based Association**：几何候选区可降低风险，不能保证零误关联；图像初步深度不准时候选可能偏移，关联后细化不等于完全重新测量。20/40 m为教师示例，不是论文消融。
- **C09 Association Error**：本例即使B的测量准确，把它分给A仍是身份对应错误。无关测量可干扰预测，但后续网络输出不由某一输入值唯一确定。详见[C13](#p003-c13)。
