# 二、CenterFusion待核实应用条目

## 1. 中心点检测（Center-point Detection）｜P003-C01

| 字段 | 待验收草稿 |
| --- | --- |
| 准确定义 | CenterFusion摘要描述先定位图像中的目标中心；中心的具体定义、坐标与监督待正文/代码核查 |
| 通俗解释 | 可把“先找目标中心，再补充目标属性”作为阅读线索；不是已验收的算法完整描述 |
| 数学或实现原理 | 热图、偏移、损失和张量维度均待原文及固定源码核查；不填猜测公式 |
| 具体例子 | 教学示意：图像中先定位一辆车的中心，再询问哪些雷达观测与其对应；非实验或论文数值例子 |
| 常见误区 | 图像中心不自动等于三维几何中心；找到中心不代表深度已准确 |
| 相关论文 | [CenterFusion摘要](https://arxiv.org/abs/2011.04841v1)；正文页码、关联CenterNet证据待核实 |
| 交叉引用 | [P003 Step 1](P003_CenterFusion.md)；[P001边界框§2–3](P001_概念查询宝典.md) |

## 2. 基于视锥的数据关联（Frustum-based Data Association）｜P003-C02

| 字段 | 待验收草稿 |
| --- | --- |
| 准确定义 | 摘要描述使用视锥关联雷达检测与图像目标中心；几何构造、过滤与候选选择待核实 |
| 通俗解释 | 从几何候选关系寻找可能属于同一目标的观测；不能因投影接近就断言同一目标 |

| 常见误区 | CRN的视锥特征构建与CenterFusion的关联策略不是同一模块；不把示意推论写成消融结论 |
