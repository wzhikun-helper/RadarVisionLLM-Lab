# Academic Writing / 学术写作

This directory stores long-term academic writing notes for RadarVisionLLM-Lab.

本目录用于长期积累 RadarVisionLLM-Lab 项目的学术写作能力。

---

## 1. Goal / 目标

The goal is not to copy sentences from published papers.

目标不是复制论文中的句子，而是学习：

* Rhetorical Function / 表达功能

* Sentence Structure / 句式结构

* Research Logic / 科研逻辑

* Technical Vocabulary / 专业术语

* Paper Organization / 论文组织方式

---


## 4. Writing Principle / 写作原则

Learn the structure and function of good academic expressions rather than copying complete sentences.

学习优秀论文中的表达结构和功能，而不是直接复制完整句子。

Every useful phrase should record:

每条值得积累的表达建议记录：

* Source Paper / 来源论文

* Original Expression / 原表达

* Function / 表达功能

* General Pattern / 通用结构

* Our Own Version / 自己的改写方式

---

## 5. Research-Writing Integration / 科研与写作结合

Writing should grow together with the research process.

论文写作不应等所有实验结束后才开始。

For example:

例如：

```text

Failure Case

失败案例

&#x20;   ↓

Motivation



Ablation

消融实验

&#x20;   ↓

Method Justification



Robustness Experiment

鲁棒性实验

&#x20;   ↓

Evaluation



Observed Limitation

观察到的局限

&#x20;   ↓

Discussion / Future Work

```

科研过程中产生的证据，应逐渐沉淀为论文内容。
