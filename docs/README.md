# Research Documentation / 科研文档

This directory stores the long-term research management documents of RadarVisionLLM-Lab.

本目录用于保存 RadarVisionLLM-Lab 项目的长期科研管理资料。

---

## 1. learning\_notes / 学习笔记

Structured notes generated during the learning process.

记录科研过程中系统学习的知识。

Examples / 示例：

* Git and Research Engineering / Git 与科研工程化

* Radar Fundamentals / 雷达基础

* Range, Angle and Doppler / 距离、角度与多普勒

* Camera Fundamentals / 相机基础

* Coordinate Systems / 坐标系

* Radar-Camera Calibration / 雷达-相机标定

* BEV Perception / BEV 感知

* Vision-Language Models / 视觉语言模型

* Multimodal Fusion / 多模态融合

Each note should explain:

每份学习笔记尽量回答：

* What is it? / 它是什么？

* Why is it needed? / 为什么需要？

* How does it work? / 怎么工作？

* What are the important terms? / 有哪些重要术语？

* How is it related to our research? / 与我们的研究有什么关系？

* What should I be able to explain after learning it? / 学完后我应该能够回答什么？

---

## 2. research\_log / 科研日志

Records the actual research process.

记录每天或重要节点实际完成的科研工作。

Each log may include:

每份日志可包括：

* What was done / 做了什么

* Why it was done / 为什么做

* Commands executed / 执行了哪些命令

* Experiments performed / 做了哪些实验

* Results / 得到了什么结果

* Problems encountered / 遇到了什么问题

* Solutions / 如何解决

* Next steps / 下一步是什么

---

## 3. weekly\_reports / 科研周报

Weekly summaries of research progress.

每周对科研进度进行一次系统整理。

Each report should contain:

每份周报应包括：

* Weekly Goals / 本周目标

* Completed Work / 已完成工作

* Papers Read / 阅读论文

* Reproduction Progress / 复现进展

* Experiments / 实验

* Results / 结果

* Problems / 问题

* New Ideas / 新想法

* Risks / 当前风险

* Next Week Plan / 下周计划

---

## 4. innovation\_bank / 创新点库

Stores candidate research ideas.

保存所有候选科研 Idea。

Each idea should contain:

每个候选 Idea 应尽量包括：

* Research Problem / 研究问题

* Motivation / 研究动机

* Closest Related Work / 最接近工作

* Research Gap / 研究空白

* Hypothesis / 科研假设

* Minimal Validation Experiment / 最小验证实验

* Novelty / 新颖性

* Feasibility / 可行性

* Experimental Cost / 实验成本

* Risks / 风险

* Current Status / 当前状态

Possible status:

状态可以是：

* Candidate / 候选

* Testing / 验证中

* Promising / 有潜力

* Rejected / 淘汰

* Completed / 已完成

Rejected ideas should not be deleted.

被淘汰的 Idea 不应删除，应记录被淘汰的原因。

---

## Core Principle / 核心原则

**Research decisions should be evidence-driven rather than intuition-driven.**

**科研决策以文献和实验事实为依据，而不是只凭感觉。**
