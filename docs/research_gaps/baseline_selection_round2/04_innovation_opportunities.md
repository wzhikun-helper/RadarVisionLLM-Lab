# 研究创新机会：候选假设，不是已验证创新

日期：2026-10-30。对象为工程证据相对有希望的MSSF、SGDet3D和LXL；SG全文和资源还需补证。代码接口存在、研究假设合理、实验有效是三个层次，本轮只到前两层。未修改模型或生成结果。

## 共同研究与评价约束

先冻结一条可复现的纯Radar-Camera基线，再研究语言。VoD/TJ4D主要是检测标注，不自动提供grounding/问答真值。3D框、类别和置信度可以作为结构化输出；雷达径向速度是输入属性，不等于已有完整3D速度预测头，也不能直接当作目标朝向上的真实速度。

至少保留原检测器、等参数非语言模块、真实文本、打乱文本、空文本/无语言五种对照；参数、训练样本、优化步数和计算预算尽量匹配。任何新增文本仅从训练划分建立；禁止用验证/测试GT编写模型推理时可见的描述。验证集可用于设计选择，但不能同时冒充未见测试证据。

闭集检测AP不等于开放词汇/语言理解。语言任务需预定义grounding IoU/定位准确率、关系宏F1或人工审核正确率；纯语言流畅性不作为几何正确性。不得为了关系题把雷达径向速度推导为未经证实的全向运动真值。

## MSSF：两个可检验问题

代码依据：[VoxelNetFuse](https://github.com/EricLiuhhh/MSSF/blob/0c9482f8b0d9dc1c43b17a68fd5312bad97e7ea7/mmdet3d/models/detectors/voxelnet_fuse.py)、[SECONDFuse](https://github.com/EricLiuhhh/MSSF/blob/0c9482f8b0d9dc1c43b17a68fd5312bad97e7ea7/mmdet3d/models/backbones/second_fuse.py)、[论文消融](https://arxiv.org/html/2411.15016v2)。

### M-A：跨模态证据冲突能否比固定语义重加权更可靠地控制融合？

| 要素 | 计划 |
|---|---|
| 原模型局限 | 多阶段采样和语义重加权存在，尚未由本轮证据证明能显式校准雷达/图像冲突；这是待验证局限，不是已测缺陷 |
| 研究假设 | 在图像低质、标定扰动或低点数区域，利用几何一致性/占用与语义不确定性控制更新，能降低错误语义传播 |
| 修改接口 | SECONDFuse.query_voxel_fuse、apply_seg_scores；先实现小型非语言可信度门控，保持原检测头 |
| 数据 | 授权VoD；固定原验证集；仅按预声明方式增加图像退化、点稀疏或外参扰动；正常集必须保留 |
| 对照 | 原MSSF、相同参数卷积/MLP门控、几何单信号、语义单信号、联合门控；匹配训练预算 |
| 指标 | 原EAA/DC AP及每类AP、稀疏/遮挡分层AP、误检/漏检、若输出概率则校准误差；延迟/峰值显存 |
| 失败原因 | 置信度可能不可靠；模型已隐式解决问题；合成扰动不能代表真实故障；门控只学会关闭相机 |
| 重叠 | RCBEVDet的对齐/门控、LXL占用、R4Det精化以及SGDet3D++证据筛选；必须证明不同机制和对应收益 |
| 语言标注 | 不需要；可先形成独立检测消融路线，VLM失败时仍有明确研究对象 |

### M-B：对象空间token与语言约束能否带来等参数非语言模块没有的几何收益？

| 要素 | 计划 |
|---|---|
| 原模型局限 | points_misc/融合BEV可提取，但当前没有语言任务、对象token或语言真值闭环 |
| 研究假设 | 将预测框/局部融合特征与明确空间关系文本对齐，在稀疏或遮挡目标上改善关系一致性，并保留检测性能 |
| 修改接口 | 对预测proposal或检测候选做RoI/局部特征聚合；轻量投影器连接冻结语言/视觉语言编码器，不直接把整个大模型端到端塞入20GB |
| 数据 | 训练集框派生“左右/前后/距离区间”等结构关系；独立人工审核关系测试集；测试推理不得提供GT生成的文本 |
| 对照 | 同参数MLP/attention、无语言、正确文本、跨样本打乱文本、类别名-only、几何关系-only；控制标签额外信息 |
| 指标 | 原检测AP、grounding定位/关系宏F1、错误关系率、推理资源；若只提升关系任务须明确，不宣称检测提升 |
| 失败原因 | 文本只是复述框标签；语言不增加传感信息；对象关联错误；高AP由额外监督而非语言模型带来 |
| 重叠 | Radar4D-VLM的proposal/场景/运动token、RCVLA的雷达相机语言交互；“新增projector”本身不新 |
| 语言标注 | 需要可审计文本或关系标注；模板可用于训练，不足以单独证明自然语言泛化 |

## SGDet3D：两个可检验问题

代码依据：[SGDet3D及插件模块](https://github.com/shawnnnkb/SGDet3D/tree/83f8c7d76f2b6d3e84ca948dee5f9e4ba472b64c/projects/SGDet3D/mmdet3d_plugin)、[实际VoD配置](https://github.com/shawnnnkb/SGDet3D/blob/83f8c7d76f2b6d3e84ca948dee5f9e4ba472b64c/projects/SGDet3D/configs/vod-SGDet3D_det3d_2x4_12e.py)。

### S-A：语义辅助在错误分割或相机缺失时是否产生可测负迁移？

| 要素 | 计划 |
|---|---|
| 原模型局限 | 几何/语义双向增强，依赖额外语义监督；尚未确认故障情况下各依赖是否相互独立 |
| 研究假设 | 对语义雷达辅助与几何深度路径分别施加受控可靠性建模，可降低错误语义引导导致的误检 |
| 修改接口 | MRF3Net语义雷达路径、GeometryDepth_Net与Cross_Modal_Fusion；提供明确旁路/冻结开关 |
| 数据 | VoD与现有预处理；分别扰动图像、预计算mask、雷达输入，记录哪些产物来自相机，避免伪装成独立雷达分支 |
| 对照 | 原模型、移除语义辅助、随机mask、置信mask、相同参数非语义门控；正常与故障集同时评估 |
| 指标 | EAA/DC AP、低点数/遮挡分层、模态失效下降幅度、延迟；检测框与语言无关 |
| 失败原因 | 去掉语义损失改变优化难度；mask缓存与图像扰动不一致；基线额外数据未齐导致虚假收益 |
| 重叠 | HGSFusion/R4Det/RCBEVDet均涉及语义融合和鲁棒性，不应把模态dropout本身当创新 |
| 语言标注 | 不需要；先确认纯检测消融可以独立成立 |

### S-B：目标导向BEV query能否支撑可解释、可反事实检验的语言grounding？

| 要素 | 计划 |
|---|---|
| 原模型局限 | 目标导向注意力不等于语言grounding，也不一定现成提供逐对象query；需核实采样与proposal接口 |
| 研究假设 | 把候选目标及其雷达支持证据组织成对象token，语言对齐在空间关系判断上优于仅图像语言对齐 |
| 修改接口 | FRPN/BackwardProjection输出与融合BEV局部特征；训练期用GT匹配分配监督，评估期只用模型候选 |
| 数据 | 合法训练集关系描述与独立grounding测试；必须同时包含可混淆近邻对象和遮挡对象 |
| 对照 | 图像-only token、雷达-only token、融合token；等参数非语言关系头；文本置换、几何位置置换与无语言 |
| 指标 | 对象定位成功率、关系宏F1、预测与传感证据一致性、检测AP保持程度 |
| 失败原因 | 候选召回限制结果；文字编码器替代不了几何；训练模板泄露关系标签；伪标注质量不足 |
| 重叠 | CVFusion实例精化、SGDet3D++对象条件证据、RCVLA交互和Radar4D-VLM token化；需明确差别 |
| 语言标注 | 需要；若没有可信语言测试集，不进入“大模型提升”论文主张 |

## LXL：两个可检验问题

代码依据：[SamplingBasedViewTrans](https://github.com/XiongWeiyi/LXL/blob/cde23c8af5dbeddfec33a34ec8c41a49b1a1a8f5/plugin/lxl/models/view_trans/sampling_based_view_trans.py)、[LXLDetector](https://github.com/XiongWeiyi/LXL/blob/cde23c8af5dbeddfec33a34ec8c41a49b1a1a8f5/plugin/lxl/models/detectors/lxl_detector.py)、[论文表VII](https://arxiv.org/html/2307.00724v4)。

### L-A：稀疏雷达占用能否表达不确定性，而不是把“没点”误当“无物体”？

| 要素 | 计划 |
|---|---|
| 原模型局限 | 采样利用深度与雷达占用；对稀疏/遮挡目标，“低占用”与“缺测”能否区分尚未验证 |
| 研究假设 | 增加点数/距离/可见性条件的不确定性表示，可减少占用对图像证据的错误抑制 |
| 修改接口 | radar_occupancy_net、feature_sampling和fuse_feats；控制参数增长，不重建整个架构 |
| 数据 | VoD；按距离、点数与遮挡分层；受控雷达dropout仅作补充，不能替代真实稀疏场景 |
| 对照 | 原占用、无占用、CRN式辅助、等参数门控、显式不确定性；所有相机骨干/训练样本相同 |
| 指标 | EAA/DC、稀疏目标召回、远距AP、置信校准、正常性能与资源开销 |
| 失败原因 | 缺测状态不可辨识；概率头无真实监督；改动仅等效于平滑；深度错误主导而非占用 |
| 重叠 | LXL原论文已有采样/占用对照，MSSF/RPGFusion与不确定性相关；必须超越重复原消融 |
| 语言标注 | 不需要；可作为VLM前的可信几何基线研究 |

### L-B：语言语义先验是否能在不伪造几何的情况下帮助缺测目标？

| 要素 | 计划 |
|---|---|
| 原模型局限 | 有图像/雷达BEV但无语言任务；对象语义先验可能诱发幻觉 |
| 研究假设 | 只允许语言调节候选类别/关系置信度，位置由传感几何约束，可降低自由文本推断带来的幻觉 |
| 修改接口 | 融合BEV的候选局部特征、检测头外的轻量校准器；先保持框回归不变以隔离语义作用 |
| 数据 | 训练类名/关系文本、独立人工审核缺测与不存在对象样本；不能直接用测试GT制造输入描述 |
| 对照 | 非语言语义分类器、语言自由调节、几何约束语言调节、打乱文本；相同负样本与计算预算 |
| 指标 | 检测AP/误检、否定对象幻觉率、grounding准确率；同时报告语言无益的结果 |
| 失败原因 | 闭集类别先验已被检测器学完；语言仅多加参数；限制语言后无增益 |
| 重叠 | RCVLA语义/物理分工、Radar4D-VLM对齐与无语言控制；“冻结LLM+adapter”已不足以构成新意 |
| 语言标注 | 需要独立语言/否定对象评价；没有标注预算时暂缓，转做L-A |

## 新工作对创新边界的影响

[SGDet3D++](https://arxiv.org/abs/2609.27671)已涉及对象条件证据、雷达几何和Doppler历史验证；[RCVLA](https://arxiv.org/html/2609.32681v1)已涉及雷达相机语言交互及轨迹仲裁；[Radar4D-VLM](https://arxiv.org/abs/2608.04130)已涉及proposal/scene/kinematic token并报告无稳定语言收益。这些都是作者报告，未在本项目复现。

因此六个月计划不能只提出“把BEV变token接LLM”。应先选择一个可测失败机制，完成非语言强对照，验证语言提供何种额外监督或推理能力。若语言收益不稳定，应如实保留零结果，而不是改变划分、挑最好seed或仅报告语言生成示例。
