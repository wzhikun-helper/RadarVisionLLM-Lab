# 可复现性评分与排名

日期：2026-10-30。辅助判断，不是成功概率，也不是论文质量的绝对排名。证据索引：[01](01_candidate_papers.md)、[02](02_code_audit.md)。**当前没有候选完成本项目运行验证。**

## 评分规则

六项按用户指定25/25/20/15/10/5计分：

- Q（25）：研究问题、公开实验、消融、协议及局限；不能由发表场所直接推到满分。SGDet3D/HP-C4D/MAFF全文消融本轮未完整核查，限制得分。
- E（25）：官方权重、精确配套配置、完整划分、实际evaluator和来源追溯。未加载权重/未跑完整评估者不能满分；链接不是二进制验证。
- T（20）：训练入口、初始化、配置与模块接口、二次开发许可和训练资源证据；未训练/许可未确认者扣分。
- D（15）：真实4D Radar+Camera主线；静态明确双分支可得15，不意味已接入VLM。MAFF只有雷达，不能靠总分补足主线。
- V（10）：可用中间特征、结构化token和可检验问题的潜力，是研究推断。本轮无语言收益实验，全部<=8。
- C（5）：硬件、依赖、存储和时间成本；服务器未知且无20GB峰值实测，全部<=3。

Q/V含研究判断；E/T/C也只是对证据完备程度的人工评分，不包装为客观测量。D依据源码/论文输入核实。相差1–3分不构成实质优势，随权重、许可、协议证据更新。

## 独立排名

### 1. 正式精读建议

优先MSSF：与CRN知识衔接，同时有体素/柱、多阶段采样和语义头等可独立验证机制，论文消融证据比单看摘要充分。LXL可作为机制对照阅读。SGDet3D、R4Det值得精读，但SG全文证据需补，R4工程缺口不因方法先进而消失。CVFusion保留高价值方法参考，不推进官方代码部署。

这只是阅读建议；本轮不启动P003正式精读，也不降低其他论文质量。

### 2. 最先做官方评估补证

1. **MSSF-PP / VoD**：选择已读ZIP配套配置和epoch_40，不自行挑一个相近仓库配置。
2. **SGDet3D / VoD**：如辅助产物可完整获得，检验发布版本目标；须补旧环境和评估链。
3. **LXL / VoD**：云盘权重、插件版本及重训目标确认后再考虑。
4. HGSFusion：先解决作者已解释的弃用导入，之后才有资格验证资源和前向。
5. R4Det：若改为TJ4D可补证；VoD路线当前暂缓。
6. HP-C4D、RaGS、RCBEVDet：优先取得精确checkpoint/配置发行资源，暂不付出构建成本。
7. CVFusion / RPGFusion：当前不能进入工程名单。

### 3. 长期可修改基线

没有正式通过者。条件优先级为MSSF > SGDet3D ≈ LXL；这个排序以源码接口和资源证据为依据，不是已成功运行。MSSF/SG/LXL还需澄清许可、完成L1/L2、验证至少一个受控消融和可训练路径。

### 4. VLM扩展

- 工程潜力先看MSSF/SGDet3D：已有可定位融合接口，能够先建立检测对照。
- R4Det/CVFusion/RaGS的实例、时序或高斯表示具有研究吸引力，但资源阻塞不能靠潜力得分抵消。
- 对象token本身、Doppler验证或语言接入已有相关工作，见[04](04_innovation_opportunities.md)。不能宣布“连接VLM”就是创新。

## 哪些新证据会改变排序

MSSF出现导入/ABI不可经济解决、权重不匹配或官方val不能对齐时降级；SG取得完整辅助产物与可构建锁定环境后可上升；HP发布精确checkpoint后重新评估E；CV发布模型代码后重新审查，而不是沿用今天结论。所有排序应绑定本轮SHA、资源版本和证据日期。
