## 统一七字段研究问题（研究设计，均未验证）

### P001-I01 / RQ1：距离、RCS与点数的可靠性诊断

1. **论文证据**：S1 p6 Table IV、Fig.4；p7 Fig.7(d)与§VI。RCS消融、远距曲线与少反射失败案例属于不同证据，不合并成RCS因果机制。
2. **观察到的限制**：少点目标可能缺几何约束；现有实验未拆开距离、类别、遮挡、RCS与点数的影响。
3. **推导**：先检查错误与这些变量的条件关联，才决定是否引入可靠性特征；不能通过归一化恢复未测得回波。
4. **假设**：在固定划分/模型并控制点数和类别后，可靠性变量仍提供可泛化的附加诊断信息。
5. **最小验证**：先做GT级距离/类别/点数分层，保存AP、Recall、定位误差；以既有特征、仅加距离、仅加RCS处理、联合特征逐项对照，固定训练协议与随机种子，报告不确定性及延迟。数据与配置获准后才执行。
6. **可能失败**：关联被点数/类别混杂解释；零回波无法凭特征补偿；校准依赖传感器或场景；额外代价超过收益。
7. **主线关系**：可作为4D Radar几何证据质量诊断，未来再考查Camera/VLM是否使用这种证据；P001并未测试VLM。

### P001-I02 / RQ2：预算约束的动态时间窗口

1. **论文证据**：S1 p4 §IV-B与p6 Table IV已做历史扫描对齐、time id和固定多扫描对照。
2. **观察到的限制**：3到5扫描整体收益变小；点数增加和时间变化没有被独立消融。
3. **推导**：固定多扫描已存在，研究问题只能是同点数/时延预算下窗口选择是否有额外价值，而非“首次使用多帧”。
4. **假设**：按局部稀疏/运动选择窗口，在受控预算下对部分目标有效。
5. **最小验证**：固定1/3/5扫描与候选窗口，匹配输入点数和允许耗时；分静态/动态目标统计AP、位置/朝向误差、拖尾案例及总延迟；保留所有time id和补偿约定。
6. **可能失败**：提升仅来自点数更多；速度是径向量导致运动误判；位姿误差/拖尾抵消收益；选择器开销过大。
7. **主线关系**：时间戳和测量来源可供后续跨模态证据组织，但到VLM的连接仅是假设。

### P001-I03 / RQ3：远距离雷视互补

1. **论文证据**：S1 p6 Table IV与p7 Fig.7(d)支持Radar-only限制；p1/§III说明有相机数据，不是已完成Camera-Radar融合对照。
2. **观察到的限制**：P001没有直接给出相机融合收益或恶劣成像融合结果。
3. **推导**：能提出互补问题，不能由Radar与LiDAR差距推出任何Camera融合都有效。
4. **假设**：具备可靠标定/同步的相机证据可能改善部分稀疏目标检测，退化成像时也可能无益。
5. **最小验证**：固定Radar-only与已确认可复现的融合基线协议，分远距/零雷达点/成像质量报告检测结果和错配案例；先查新和工程审查，再决定是否设计新模块。
6. **可能失败**：相机深度歧义、标定偏差、域变化；与既有融合方法重合；资源不足，不能靠增加参数宣称方法贡献。
7. **主线关系**：Camera融合直接相关；VLM还需对象对应和事实判据，P001不能证明其收益。
