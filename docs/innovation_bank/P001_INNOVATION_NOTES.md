# P001 Innovation Bank 解释与评分口径

此文件的 CSV 是**候选研究假设**而非已验证创新。新颖性/可行性/论文潜力/成本分数均为主观初评（1–5），不可当作客观排名。成本 5 代表较高成本。

- **I01**：先检验 RCS/距离/点数与错误率的关联，再设计特征；不可把补出的特征当作真实回波。
- **I02**：多帧已由 P001 验证，必须通过“动态策略 vs 固定帧数”且控制点数/计算成本来体现差异。
- **I03**：DDCFusion 等已有相关融合机制；需系统检索和可复现基线后才能提出真正差异。

建议每项补充：相关工作矩阵、最小实验结果、失败案例、训练资源估计、是否保留/淘汰的决策记录。
