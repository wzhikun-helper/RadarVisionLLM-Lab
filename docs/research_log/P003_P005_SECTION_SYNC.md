## 章节同步门槛

第一遍顺序：Abstract → Introduction → Methodology → Experiments → Related Work → Conclusion。每节可先标“草稿 / 待验收”；只有真实题答、教师批改及明确通过结论齐备，才能登记“教师验收通过”。缺原文不能由Codex代答、代批改或从目录存在推断通过。

每节验收后在同一独立分支提交中同步核对：

1. 精读：基本信息、章节/页码，原文论点与中文解释、基础概念、公式/符号/张量或几何例子、图表、贡献与实验依据、局限、推论和待验证假设、原题/真回答/批改/补答/验收。
2. 概念：先检索P001/P002及本论文宝典；已有定义用交叉引用并补本论文应用，不重复复制；新概念独立编号。每条列中英文名、准确定义、通俗解释、数学/实现原理、具体例子、误区、论文来源与交叉引用；未知填“待核实”，不能用教师推测替代论文结论。
3. 创新：仅对有研究价值的问题建候选；分论文证据、我们的推论、未查新想法、可检验假设和最小实验。没有查新与实验不宣称创新，不按章节自动产生想法。
4. 日志：真实学习日期/时长（未知留空）、章节、状态、原始对话来源、涉及概念ID、修改路径、验收证据及后续任务。
5. Git：检查链接/索引/JSON/CSV、状态一致性和原始资产SHA，仅暂存本次文件；普通推送后核对远程SHA。若并发冲突或修改无法隔离，停止并报告。提交与远程链接记录在交付中；后续可追加到日志，不预填虚假SHA。
