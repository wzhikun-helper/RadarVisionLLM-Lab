# 文献登记

- [paper_matrix.csv](paper_matrix.csv)：36列主矩阵，登记论文属性、方法、学习状态与项目关系。
- [paper_matrix_P001_import.csv](paper_matrix_P001_import.csv)：保留的P001原始23列导入记录，用于来源追溯。
- [正式笔记入口](../paper_notes/README.md)：逐篇精读与概念宝典。

## 登记规则

1. 每篇论文使用唯一ID；P001为VoD，P002为CRN，P003为R4Det，P004为MSSF。
2. 以正式论文和作者来源为准；尚未核查的字段留空，不推测指标、开源状态或复现难度。
3. 原始导入表先按字段映射核对，不能直接追加到列结构不同的主矩阵。
4. 阅读状态、代码精读和模型复现分别记录。作者报告的结果不填作本项目结果。
5. 论文PDF、数据和权重不在此目录批量存放；外部资源遵循其原始访问与使用条件。

修改主表后，核对36列结构、ID唯一性与笔记入口；不要将研究设想写成论文已有贡献。

## P002 CRN详细登记

主矩阵已有唯一P002行，已按用户提供的正式论文核对全部36列。[CRN登记说明](P002_CRN_RECORD.md)列出逐字段依据、论文页/节/图表、作者报告指标及未核实边界。P001独立导入表仅保留历史来源，本次未修改，也不机械复制为P002导入表。
